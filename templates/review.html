Cách duyệt — hướng dẫn chi tiết
  1. Đọc: bấm vào tiêu đề để mở bản nháp.
  2. Ổn rồi: bấm ✅ Duyệt & đăng. Trang GitHub mở ra với nội dung điền sẵn, bạn chỉ cần bấm nút xanh Create (Tạo). Lần đầu GitHub có thể hỏi đăng nhập.
  3. Chờ 3–5 phút: GitHub tự đăng bài, cập nhật web, rồi trả lời kèm đường link và tự đóng mục đó.
  4. Muốn sửa: bấm 💬 Nhờ Claude sửa để chép sẵn lời nhờ, dán vào Claude và ghi điều muốn sửa. Sửa nhanh vài chữ thì dùng ✏️ Tự sửa trên GitHub.

Trang này không hiện trên Google và không có trong dữ liệu cho AI. Ai có đường link vẫn mở xem được, nhưng chỉ chủ kho trên GitHub mới duyệt hay bỏ được bài.{% if issues_url %} Xem các lần duyệt gần đây.{% endif %}
